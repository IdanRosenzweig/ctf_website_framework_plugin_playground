# overview

this repo contains a plugin for ctf_website_framework that displays information about the attack playground.

# use

to use the plugin, simply put the repo inside the plugins directory

(e.g. from github `git clone "https://github.com/IdanRosenzweig/ctf_website_framework_plugin_playground" "_parent_dir_/ctf_website_framework/CTFd/plugins/ctf_website_framework_plugin_playground"`)
